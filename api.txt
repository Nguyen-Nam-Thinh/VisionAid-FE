1. Login -> GET me -> refresh -> GET me -> logout; lỗi không fallback mock.
2. PUT me -> GET/reload; change-password -> phiên bị xóa -> login mật khẩu mới.
3. Forgot-password -> email/token -> reset-password -> login. Cần SMTP/inbox test.
4. POST users -> giữ userId -> POST caregiver-links -> GET links/users. Link lỗi không tạo user lại.
5. Organization -> staff/VIU cùng org -> link -> resource; test org khác bị cấm.
6. Mobile POST GPS -> Web GET live/history -> SignalR. Không gửi GPS giả bằng Web.
7. Mobile emergency -> Web list/detail -> acknowledge/escalate/resolve; test conflict.
8. Person -> upload photos -> GET trạng thái -> primary/delete; cần contract đọc ảnh mã hóa.
9. TTS PUT -> GET -> Mobile đọc lại; không tự kết luận đã đồng bộ thiết bị từ HTTP 200.
